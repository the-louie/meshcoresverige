Roslagen is not its own region on meshcoresverige.se today. Roslagen is in Stockholm County, but
northern Roslagen is in Uppsala County. Use the values for the county you are in:

{{< lan-area "01" "03" >}}

Today the regions follow the counties. An area like Roslagen can get its own subregion within the county if the people
building the mesh there want one: contact louie on [Sweden Mesh Discord](https://discord.gg/gchSzHkPGG) and we'll talk about it.

Read more about how the regions work in [Regions](/guider/regioner/), or start with
[Get started with MeshCore](/kom-igang/).
